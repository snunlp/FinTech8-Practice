## 서울대학교 빅데이터 핀테크 전문가 과정 11기 — 자연어처리 실습 커리큘럼

현업 적용 중심의 자연어처리(NLP) 실습 과정입니다. PyTorch 기반 기본기부터 Transformer·LLM·에이전트까지 단계적으로 다루며, 매 회차 사전 학습과 실습으로 실무 역량을 강화합니다.

### 교육 목표
- PyTorch 텐서/미분/최적화 기본기 확립
- 분류·Seq2Seq 등 핵심 NLP 모델 구현
- Transformer·Hugging Face 기반 파이프라인 설계
- LLM(QLoRA, SFT, DPO/ORPO, RAG) 및 에이전트 실습
- 팀 프로젝트를 통한 E2E 문제 해결

### 대상 및 요구사항
- 파이썬 기본 문법, 머신러닝/딥러닝 개념
- 개발 환경: CoLab, (기타: Python 3.10+, PyTorch, CUDA(선택), VS Code/Jupyter)

### 사용 도구
- PyTorch, TorchText, Hugging Face Transformers/Datasets, PyTorchLightning
- scikit-learn, pandas, WandB(선택), Gradio/Streamlit(선택)

## 세부 커리큘럼

### 1회차 — PyTorch 기초 및 텐서 연산
- 텐서 생성/브로드캐스팅/인덱싱/벡터화
- 자동미분과 Optimizer, 손실함수 설계
- 학습 안정화(초기화, 정규화, 스케줄러)
- *미니 프로젝트: 선형/로지스틱 회귀 구현

### 2회차 — NLP 기초
- 토큰화, 어휘(vocab) 설계
- 임베딩과 간단한 FFN 텍스트 분류기
- 데이터 전처리 파이프라인

### 3회차 — 분류·Seq2Seq 기초
- 감성분석(이진/멀티 클래스) 분류 모델
- RNN 기반 Seq2Seq(Teacher Forcing, 스케줄링)
- 학습/추론 파이프라인, 체크포인트 관리

### 4회차 — Transformer·Hugging Face 실습
- Transformer 구조(Attention, Masking) 적용
- HF 토크나이저/모델 로딩, BERT/GPT 파인튜닝
- 실전 팁: 학습률 스케줄, mixed precision, 평가지표

### 5회차 — LLM 파인튜닝·중간 발표
- SFT 파이프라인, 데이터 구성 전략
- DPO/ORPO 개념 및 실습 흐름 안내
- 팀별 중간 발표(평가 반영)

### 6회차 — RAG와 프로젝트 설계
- RAG 개념: 검색-생성 결합, Hallucination 저감
- 인덱싱/리트리버/리랭커 구성
- 팀별 프로젝트 파이프라인 설계 및 피드백
- 배포 고려: 간단한 API/데모(선택)
  
### 7회차 — 에이전트 AI
- 에이전트 아키텍처와 파이프라인
- Tool Calling, 계획/메모리, 오류 복구 전략
- 프로젝트 보완 및 성능 개선

### 8회차 — 최종 발표
- 팀별 최종 발표 및 데모
- 코드 품질/재현성/윤리·보안 점검
- 피드백 및 고도화 방향 제안
